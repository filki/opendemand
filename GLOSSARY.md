# Glossary

Vocabulary for issues, tests, ADRs, docs, and UI copy. Definitions here are concise; the authoritative semantics live in `docs/architecture/DATA_ARCHITECTURE.md` and the ADRs under `docs/architecture/adr/`. Use these terms as written — do not drift to synonyms.

- **Adjacent revisions** — the two newest import revisions of the active source profile; the default weekly comparison never skips an unforecast revision (ADR-0022).
- **Actuals confirmation** — append-only declaration that one actuals revision is complete through a finished week; the latest row is current and pins the revision every retrospective score uses (ADR-0030).
- **Backtest origin** — one rolling-origin training cutoff per model inside a forecast run; a run plans up to four (`origin_index` 1–4), each with its own origin date and train size.
- **Baseline forecast** — immutable model output for one product/location/week cell. Never edited; manual edits are overrides.
- **canonical/1** — the frozen CSV input contract: `series_key`, `week_start`, `quantity`. Raw planner exports are converted into it by the preprocessing layer (ADR-0019); the contract itself does not change.
- **Champion** — the statistically preferred model for one series in one run after backtesting; Rust selects it per series, and the rules live in ADR-0017 (which supersedes the champion rule of ADR-0006).
- **Champion eligibility** — a model needs at least two completed backtest origins for one series before it can be ranked.
- **Comparable evaluation set** — the origin dates completed by every champion-eligible candidate for one series; the selection score pools errors only over these origins, never over unequal evidence.
- **Content hash** — SHA-256 of the original retained source bytes (CSV, TXT, or XLSX), qualified by the input contract version; part of the import idempotency key.
- **Coverage** — share of series in a run whose outcome is `ok` or `fallback_naive`.
- **Effective forecast** — derived at read time as the latest override ?? baseline. Never stored.
- **Evidence fingerprint** — deterministic hash of what a review acknowledgement covered (the run outcome/reason for one series plus its cell override revision map); a mismatch at read time makes the series unreviewed again (ADR-0027).
- **Demand change** — a read-time cell difference between two revisions at one `product × location × week_start`: `added`, `removed`, or `changed` quantity/status; `missing` stays distinct from zero (ADR-0022).
- **Eligibility status** — per series × model × run: `not_eligible` (below the model floor), `production_only` (too few completed origins), or `champion_eligible`.
- **Exception inbox** — derived, read-time ranked list of exception series for one completed run, with fixed rule priority; review state filters rows but never suppresses evidence, and nothing is stored (ADR-0028).
- **fallback_naive** — a run outcome: no champion was available (too few completed origins, or no origin common to all candidates), so the Naive baseline was used; flagged.
- **Forecast bias** — `sum(forecast − actual) / sum(|actual|)` pooled over a model's completed origins; positive means overforecasting; unavailable when the actual total is zero; diagnostic only, never a ranking input.
- **FVA (retrospective)** — baseline WAPE minus published-effective WAPE in percentage points over one series' scored points at one horizon step; positive means the planner's adjustment helped (ADR-0030). Not a cross-SKU score.
- **Forecast change** — a read-time baseline difference between two runs at the same `week_start`; horizon edge weeks are non-comparable and count as no change (ADR-0022).
- **Forecast run** — immutable record of one forecast execution; pins the import revision, horizon, timezone, config, and versions.
- **H (usable history)** — number of consecutive weeks with numeric values ending at the last completed week; `missing` and `partial` weeks break the run (ADR-0005).
- **Hindsight (exclusion)** — a target actual that existed in a profile revision at or below the publication's revision high-water mark: the planner could have seen it, so the point is never scored (ADR-0030).
- **Import revision** — immutable full-snapshot import; never mutated or auto-deleted.
- **MAE** — mean absolute error: `sum(|actual − forecast|) / 12` over one backtest origin's 12-week horizon.
- **Import configuration** — a named, profile-scoped parsing descriptor the guided import can save and reuse; editing or deleting one never changes a committed revision, which keeps its own frozen snapshot (ADR-0021).
- **Mapping fingerprint** — identity of the mapping plan an import used; part of the idempotency key together with the content hash. For preprocessed imports the plan includes the parsing descriptor digest (ADR-0020).
- **Material change** — derived inbox evidence: the sum of absolute baseline deltas over common calendar weeks between two adjacent runs, plus its ratio to the previous baseline magnitude (null when that magnitude is zero); the rule fires only when both configured thresholds are met (ADR-0028).
- **model_failure** — a run outcome: no fallback candidate produced a forecast; the run records the failure and invents no values.
- **Observation status** — one of `known`, `zero`, `missing`, `return`, `correction`, `stockout`, `partial`; `missing` and `partial` carry NULL quantity and break `H`.
- **Parsing descriptor** — the versioned, deterministically serialized description of how one source file becomes observations (format, encoding, delimiter or sheet, header row, column bindings, date formats, separators, aggregation); it joins the mapping fingerprint and is frozen per preprocessed revision (ADR-0019, ADR-0020).
- **Override** — append-only manual edit to a forecast cell; revisions are sequential, NULL clears, the highest revision wins, and overrides are scoped to one run.
- **Plan publication** — immutable official commitment of one completed run for its history cutoff: pins the exact latest override revision of every overridden cell and the profile's highest import revision id at publication time; published values are derived from those pins, one publication per profile and cutoff (ADR-0029).
- **Override reason** — the required planner reason code stored with each new override revision (`promotion`, `customer_information`, `supply_constraint`, `data_quality`, `other`); `other` requires a note. It records intent, never a detected cause (ADR-0027).
- **Review event** — append-only acknowledgement (`reviewed` or `reopened`) of one series in one run, stored with the evidence fingerprint it covered; the current state is derived at read time (ADR-0027).
- **Review policy** — append-only versions of the profile-scoped material-change thresholds (absolute and relative); both set enables the rule, both empty disables it, and the highest version is current (ADR-0028).
- **Revision high-water mark** — the highest import revision id visible to a publication; target actuals present at or below it cannot have influenced the plan, so they bound the hindsight check for later evaluation (ADR-0029).
- **Run outcome** — one of `ok`, `fallback_naive`, `insufficient_history`, `model_failure`, `invalid_data`.
- **Selection score** — pooled WAPE over the comparable evaluation set, or pooled MAE when that set's actual total is zero; lower is better (ADR-0017).
- **Series** — one product × location pair; the unit of history, qualification, and forecast status.
- **Series note** — append-only, profile-scoped planner note attached to one series; it survives across runs and never changes plan values, coverage, or stored history (ADR-0027).
- **Series qualification** — per-revision eligibility: `eligible`, `insufficient_history` (`H < 12`), or `invalid_data`.
- **SKU** — the product's canonical display code; product identity is the UUIDv7 id, not the SKU (ADR-0004).
- **WAPE** — weighted absolute percentage error: `sum(|actual − forecast|) / sum(|actual|)`; unavailable when the actual total is zero (MAE fallback).
- **Weekly comparison** — derived, read-time comparison of two adjacent import revisions and their completed forecast runs; never stored, never zero-filled (ADR-0022).
- **week_start** — ISO date (`YYYY-MM-DD`) of the Monday that identifies a calendar week in the workspace timezone.
- **Workspace** — the user-chosen directory holding the SQLite database, retained source CSV copies, exported CSV copies, backups with manifests, and job temp files. The workspace name is its folder name; renaming a workspace moves the folder and deletion removes the whole directory (ADR-0024).
