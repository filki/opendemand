# AGENTS.md

OpenDemand is a local-first, SKU-level demand forecasting desktop application: one user, one local workspace, all business data on the machine, no network listeners. Milestone 1 — **canonical CSV → SQLite → Python Naive forecast → Rust persistence → Svelte chart** — is in development; `README.md` carries the honest status. Technical artifacts, docs, tests, and code are English.

## Approved stack — preserve it

Decisions live in `docs/architecture/adr/` (start at `README.md` there); do not reopen them in passing.

- **Shell**: Tauri v2 with a static SvelteKit frontend (adapter-static, Svelte 5 runes, TanStack Query) and typed IPC generated by `tauri-specta`. The frontend sends typed commands and renders results; it never accesses the filesystem or SQLite.
- **Core**: the Rust core is the sole owner of the workspace SQLite database — single serialized writer, WAL, `synchronous=FULL`, one transaction per persist. It owns validation, job orchestration, model selection policy, and backups.
- **Sidecar**: Python forecasting engine, one process per job, Arrow IPC files plus versioned JSONL on stdin/stdout; it never opens the database.
- **MCP**: a later, opt-in, read-only adapter; it stays out of Milestone 1.

## Current-phase rules

- **Migration 001 is frozen.** `docs/architecture/schema/001_init.sql` passed 44 integration/recovery tests on 2026-10-13. Its SHA-256 is recorded in `001_init.sha256`. Never edit it; schema changes require a new numbered migration and verified backup.
- **Stay in Milestone 1.** Changes advance the chain above. MCP, XLSX export, seasonal models, flexible raw-file parsing, and advanced workspace management enter only after Milestone 1 works end-to-end.
- **Accepted ADRs are historical.** To change a decision, add a new ADR that supersedes the old one; the old record keeps its text.
