Demand forecasting that stays on your computer.

OpenDemand is a desktop app for weekly demand forecasting. Load a planner export — CSV, TXT, or Excel — map the columns once, and reuse the saved mapping every week. The app forecasts every product with the best of three models, you can adjust single weeks, compare the newest run with the previous revision, and export the full plan. All data stays on your computer. You do not need an account. The app does not send data to the internet.

What it does today

New to the app? Try the sample workflow: two small files (snapshot A, a later import) show a guided import, a first forecast, then a separate forecast and comparison for newer data — no real data needed.

  1. Add your data

    Load a raw CSV, TXT, or Excel export from your planning system. The guided import detects the format, lets you map the columns on a parsed preview, and saves the mapping as a configuration you reuse on the next export. Each import is stored as a complete copy.

  2. Generate a forecast

    After importing, choose Generate forecast when you are ready. If weeks are missing, decide whether to estimate them for this forecast; stored history stays unchanged. The app selects the best of three models (Naive, SeasonalNaive, AutoETS) per product. Everything runs locally; you do not need Python or other tools.

  3. Compare runs and adjust

    Choose Compare runs to review the latest import against the previous one. Inspect demand edits and forecast movement, then adjust single weeks by hand and compare them with the untouched baseline.

  4. Export the plan

    Export the whole plan of the selected run to CSV or XLSX — every product, all 12 weeks. Exports never overwrite an existing file.

Honest status

The main features work in development and automated tests check them. The installer is experimental. The app is not ready for production use.

Works today

  • Guided import of raw CSV, TXT, and Excel exports with a live preview and validation
  • Saved import configurations: one mapping reused every week
  • Naive, SeasonalNaive, and AutoETS forecasts with automatic per-product selection
  • Separate import, on-demand forecast, and manual run-comparison actions
  • Per-forecast choice to estimate missing weeks without changing stored history
  • Demand changes and baseline forecast deltas between two revisions
  • Manual week-by-week forecast changes compared with the baseline
  • Full-run CSV and native XLSX export with Plan and Summary sheets
  • Persistent run coverage and exception overview
  • Weekly comparison filters for demand, forecast, and series presence changes
  • English, Polish, and Spanish language selection for import and weekly review
  • Automated tests for data, engine, app, and packages

Not built yet

  • Periodic backups and restore (a pre-migration backup exists)
  • Weekly import-and-forecast orchestration (planned for Pipelines)
  • Scheduled imports
  • The optional read-only MCP connection

Open source under AGPL-3.0-only. No telemetry and no accounts. The app runs offline.
