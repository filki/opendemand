Demand forecasting that stays on your computer.

OpenDemand is a desktop app for demand forecasting. Add your weekly numbers from one CSV file. The app calculates a forecast and shows a chart. All data stays on your computer. You do not need an account. The app does not send data to the internet.

Download v0.0.2 See the code

Unsigned development preview. License: AGPL-3.0-only. Builds for Windows x64, macOS on Apple Silicon, and Linux x64.

What it does today

  1. Add your data

    Use one CSV file with three columns: product key, week, and quantity. Each import is saved as a complete copy.

  2. Get a forecast

    The app makes a simple baseline forecast for every product. Everything runs on your computer. You do not need Python or other tools.

  3. Keep your results

    The app saves every run and its results on your computer. Open a chart again at any time.

Honest status

The main features work in development and automated tests check them. The installer is experimental. The app is not ready for production use.

Works today

  • Weekly history import from a CSV file
  • Baseline forecast with the built-in engine
  • Manual forecast changes with a baseline comparison
  • Full-run CSV export
  • Run history and charts on your computer
  • Automated tests for data, engine, app, and packages

Not built yet

  • Backup and restore
  • XLSX export
  • Seasonal models
  • Flexible import of raw planner files
  • The optional read-only MCP connection
