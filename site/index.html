Demand forecasting that never leaves your machine.

OpenDemand is a local-first desktop app for SKU-level demand forecasting. Import a weekly history, run a forecast through a bundled Python engine, and keep every result in a workspace you own — the SQLite database and the retained source CSVs live in a folder you choose. No accounts, no telemetry, nothing listening on the network.

Download v0.0.2 Read the source

An unsigned development preview, licensed under AGPL-3.0-only, built for Windows x64, macOS on Apple Silicon, and Linux x64.

What it does today

  1. Import a weekly history

    One CSV with three columns: series key, ISO week (Monday), and weekly quantity. Every import is stored as a full, immutable snapshot.

  2. Run the forecast

    A bundled Python engine computes the Naive baseline, one process per job, and returns results as Arrow IPC. No Python installation is needed.

  3. Keep every result

    Runs persist to a local SQLite database owned by the Rust core and reopen as charts. Typed IPC, no hidden state.

Honest status

Milestone 2 planner features are implemented in development, verified by automated tests against a real workspace. Packaging is experimental and nothing here is ready for production use.

Works today

  • Canonical CSV import (the canonical/1 contract)
  • Naive forecasting through the bundled Python sidecar
  • Persisted run history and forecast charts
  • Run-scoped manual overrides with baseline vs. effective comparison
  • Full-run CSV export
  • Automated tests: schema and recovery, engine, frontend, and per-platform packaging checks

Not built yet

  • Backups and restores
  • XLSX export
  • Seasonal and other forecasting models
  • Flexible parsing of raw planner files
  • The optional read-only MCP adapter
